# TVAL3 beta 2.4 license information

## Preserved upstream statement

The TVAL3 beta 2.4 distribution preserved for this tutorial states in
`Solver/readme.txt`:

> TVAL3 is free software, and you can redistribute it and/or modify it under the
> terms of the GNU General Public License as published by the Free Software Foundation.

The upstream notice does not name a GNU GPL version.

## Machine-readable representation

The repository therefore does not assign TVAL3 a version-specific SPDX license
identifier. Instead, `REUSE.toml` associates both bundled TVAL3 directories with:

```text
LicenseRef-TVAL3-GPL-Unversioned
```

The corresponding preserved license notice is stored in:

```text
LICENSES/LicenseRef-TVAL3-GPL-Unversioned.txt
```

This custom identifier records the upstream situation without relicensing TVAL3
and without choosing a GPL version on behalf of the original authors.

The original tutorial code and documentation remain under BSD-3-Clause.
